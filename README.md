# nastachku-2026

Презентация «SRE MCP: как пустить ИИ в инцидент и не отдать ему прод» — read-only по умолчанию, человек на кнопке и три места, где эта схема ломается. Доклад Михаила Савина, Head of SRE в [h3llo cloud](https://h3llo.cloud), для Стачки 2026.

Слайды онлайн: <https://jtprogru.github.io/nastachku-2026/>

Собрана на [Slidev](https://sli.dev) с темой [slidev-theme-bear](https://github.com/jtprogru/slidev-theme-bear). Исходником был Bento-дек `SRE-MCP-doklad_bento.html`: текст слайдов и заметки спикера перенесены из него.

## Структура

`slides.md` — точка входа: headmatter, титульный слайд и порядок подключения остальных слайдов через `src:`. Всё, кроме титула, лежит по одному слайду в файле в `pages/NN/`, где `NN` — блок доклада:

- `pages/00/` — вступление: спикер, дисклеймер, обещание залу, контур;
- `pages/01/` — арифметика MTTR;
- `pages/02/` — что такое SRE MCP, схема и контракт ответа;
- `pages/03/` — права и пять гейтов;
- `pages/04/` — разбор ночного инцидента;
- `pages/05/` — где схема ломается;
- `pages/06/` — цифры и как начать;
- `pages/07/` — итоги, материалы, QR-коды на слайды и канал, вопросы;
- `pages/backup/` — бэкап-слайды «если спросят».

Каждый блок открывается своим `section.md`. Frontmatter слайда (лейаут, `routeAlias`) живёт в самом файле страницы, в `slides.md` остаются только `src:` и `hide:`.

Слайд `pages/06/audit-start.md` опциональный: он режется первым, если не укладываешься по времени. Для этого в `slides.md` у него стоит `hide: false`, достаточно поменять на `true`.

## Переходы по клику

Часть слайдов связана ссылками через `routeAlias`:

- «База раннбуков» на схеме (`arch`) ведёт в drill-down `context-layer` и обратно;
- карточки на обзоре гейтов ведут на `gate-1`, `gate-2-3`, `gate-4`, `gate-5`.

## Бэкап-слайды

`pages/backup/stack.md` и `pages/backup/cost.md` подключены в конце `slides.md` с `hide: true`. Скрытых слайдов, как в Bento, в Slidev нет: `hide: true` выкидывает слайд из показа, сборки и PDF целиком, и ссылка на него перестаёт работать. Поэтому кнопок на бэкапы на слайде «Вопросы» сейчас нет.

Чтобы вернуть бэкапы в дек, убери у них `hide: true`. Они встанут после «Вопросов», будут доступны стрелкой вперёд, а на каждом уже есть ссылка «← вернуться к вопросам» на `routeAlias: questions`.

## Цифры

Цифры на слайдах `pages/01/mttr.md` и `pages/06/metric.md` настоящие: медианы по архиву из 48 постмортемов за февраль–сентябрь 2026. Как считали, откуда брали начало отказа и какие оговорки проговаривать вслух, записано в заметках спикера этих слайдов.

## Компоненты

`Kicker`, `SectionNum`, `Card`, `Callout`, `BarChart` и `Mascot` приходят из темы, их описание — в [README slidev-theme-bear](https://github.com/jtprogru/slidev-theme-bear#readme). Маскот монохромный: `style.css` переопределяет `--mascot-ink` на `--fg-muted`, тот же тон, что у знака в футере.

Своё в `components/` только одно, подключается автоматически:

- `ArchDiagram` — схема «все стрелки — read, одна пунктирная — propose».

На плотных слайдах основной текст уменьшает scoped `<style>` в конце файла страницы. Заголовки при этом остаются в размере темы и не прыгают от слайда к слайду.

## Useful

Все цели — в `make help`. Зависимости ставятся через `npm ci` автоматически, если `node_modules` нет или манифесты новее.

Запустить development-сервер:

```shell
make dev
```

Собрать статический сайт в `dist/`:

```shell
make build
```

Собрать готовый PDF:

```shell
make export
```

Тёмная тема собирается в отдельный `slides-export-dark.pdf`, светлый PDF при этом не перезаписывается:

```shell
make export THEME=dark
```

## Деплой

Workflow `.github/workflows/build.yaml` на каждый push в `main` собирает дек с `--base /nastachku-2026/` и выкладывает на GitHub Pages. Его же можно запустить руками через `workflow_dispatch`. Зависимости npm и версии actions обновляет Dependabot раз в неделю.
