# Ассистент — не особый случай

<div class="grid grid-cols-[2fr_3fr] gap-10">

<div>

Мы не строили отдельную систему прав под ИИ. Ассистент получил идентичность в той же модели доступа, которую до него строили для людей и подрядчиков.

<p class="text-xl font-bold leading-snug text-link">Если у вас нет модели доступа для людей, ИИ её вам не заменит — он её вскроет.</p>

> Два класса инструментов: диагностика доступна всегда, даже при включённом kill-switch. Процедуры — отдельный класс, недоступный роли `sre-readonly`.

</div>

<div>

| модель доступа | в которую он встаёт |
| --- | --- |
| **Нулевой baseline** | после заведения нет ни read, ни write |
| **Персональный субъект** | своя учётка, а не общий сервисный аккаунт |
| **Прод — временно** | гранты функций с TTL и обязательным approver'ом |
| **Git — источник правды** | изменение доступа = merge request, а не `kubectl` |
| **Policy-guard'ы** | субъект не выходит за свою область |
| **Break-glass отдельно** | аварийный доступ есть, но вне этой модели |

</div>

</div>
