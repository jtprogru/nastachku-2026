# У ассистента нет своей учётки

<div class="grid grid-cols-[2fr_3fr] gap-10">

<div>

Ассистент ходит в sre-mcp под сертификатом инженера. Роли правятся руками в `subjects.yaml`, без TTL и approver'а, отзыв срабатывает после рестарта.

> Диагностика работает всегда, даже когда kill‑switch выключил все процедуры. L1 доступны ролям sre‑oncall и sre‑admin, L2 только sre‑admin.

</div>

<div>

| модель для людей | что требуется |
| --- | --- |
| **Нулевой baseline** | после заведения нет ни read, ни write |
| **Персональный субъект** | своя учётка, а не общий сервисный аккаунт |
| **Прод — временно** | гранты функций с TTL и обязательным approver'ом |
| **Git — источник правды** | изменение доступа = merge request, а не `kubectl` |
| **Policy-guard'ы** | субъект не выходит за свою область |
| **Break-glass отдельно** | аварийный доступ есть, но вне этой модели |

<p class="text-sm font-bold mt-2" style="color: var(--c-danger-text)">Ассистента в неё ещё надо поставить</p>

</div>
