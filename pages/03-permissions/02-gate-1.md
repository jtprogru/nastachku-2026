# Read-only живёт в сервере. Пока не в токене

::left::

<Card kicker="держит сегодня" class="text-xl">

- **ArgvGuard**: режет секреты, RBAC и port-forward до запуска
- **Сеть**: снаружи только mTLS

</Card>
